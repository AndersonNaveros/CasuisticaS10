# Desarrollo de un sistema de exportacion agricola

Proyecto desarrollado en PHP para la casuistica de la Semana 10 del curso de Desarrollo Web.

## Descripcion

El sistema permite registrar lotes de productos agricolas de AndesPeru Export S.A.C. y consultar sus exportaciones.

## Funcionalidades

- Registro de productos agricolas.
- Almacenamiento de datos en formato CSV.
- Calculo del valor total exportado.
- Identificacion de lotes de alta exportacion.
- Identificacion de destinos especiales.
- Filtro de exportaciones por pais.
- Reporte con opcion de guardar como PDF.

## Tecnologias utilizadas

- PHP
- HTML
- CSS
- Bootstrap 5
- XAMPP (Apache)

## Ejecucion

1. Colocar la carpeta Casuisticas10 dentro de htdocs.
2. Iniciar Apache en XAMPP.
3. Abrir http://localhost/Casuisticas10/index.php

## Archivos principales

- index.php: formulario.
- registrar.php: registro y validacion.
- reporte.php: consulta y estadisticas.
- estilo.php: presentacion.
- exportaciones.txt: almacenamiento CSV.
